## 🚨 작업 전 필수 3단계

### 1. **파일 상단 변경 이력 읽기** (수정 시)
```python
"""
변경 이력:
2026-07-28 14:20 | 김철수 | 버그 수정 #123

  - 원인: retry_count 체크 누락

```
→ **안 읽으면**: 이미 고친 버그 또 만듦

### 2. **README.md 읽기** (신규 작업 시)
→ **안 읽으면**: 이미 있는 모듈 또 만듦, 파일 위치 틀림

### 3. **design/15-coding-guidelines.md 읽기**
→ **안 읽으면**: 규칙 위반, 유지보수 불가능

## 🚫 절대 금지 (HARD RULES)

### 1. 정규식으로 SQL/XML 파싱 금지
```python
# ❌ 절대 금지
re.search(r'SELECT\s+(.+?)\s+FROM', sql)

# ✅ 허용 (단순 감지만)
re.search(r'@[\w\.]+', sql)  # DBLINK 있는지만
```

### 2. sed 절대 금지
```bash
# ❌ 절대 금지
sed -i 's/SYSDATE/CURRENT_TIMESTAMP/g' *.xml
```
→ Python으로 처리

### 3. 전역 변수 금지
→ 의존성 주입 사용

### 4. 하드코딩 금지
→ config.get() 사용
